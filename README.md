# GUI Calculator with History

A simple calculator project built using Python. It performs basic arithmetic operations and saves calculation history.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Calculation history
- Clear history
- Division-by-zero protection
- Simple command-line interface

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python calculator_with_history.py
